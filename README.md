# project-JS

Shopping Site Project - First Year
This is a Client-Side web application developed during my first year of studies. While it focuses on the frontend, it includes complex logic to handle core e-commerce functionalities.

🚀 Key Features
User Authentication: Complete registration and login flow for users.

Advanced Shopping Cart: Sophisticated logic for adding, removing, and updating products in real-time.

Product Management: Dynamic rendering of products and categories.

Complex Logic: Intensive use of JavaScript to manage state and data flow without a backend.

🛠️ Tech Stack
HTML5 & CSS3

JavaScript (ES6+)
